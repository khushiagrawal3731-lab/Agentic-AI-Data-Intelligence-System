# Agentic AI Data Intelligence System

## Overview
A multi-agent AI workflow developed using n8n for real-time web research, intelligent analysis, recommendation generation, and automated Telegram responses.

## Technologies Used
- n8n
- Groq LLM
- Tavily Search API
- JavaScript
- Telegram Bot
- Notion AI

## Workflow Features
- Real-time web research
- Multi-agent AI execution
- Automated data cleaning
- AI-based analysis
- Recommendation generation
- Telegram integration

## Workflow Architecture
User Query → Planner Agent → Research Agent → Analysis Agent → Recommendation Agent → Final Decision Agent → Telegram Output
